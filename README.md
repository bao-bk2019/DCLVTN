# Welcome to Our Project!

# Install Enviroment
## For Mac
**Install environment:** 

`virtualenv env`

**Run environment:**

`source env/bin/activate`

## For Window

**Install environment:**

`python -m venv env`

**Run environment:**

`env/Scripts/activate`
# Install Packages

`pip install -r requirements.txt`

# Run Docker

`docker compose up -d`


# Run Program

## Run Server
**Go to folder server:**

`python manage.py runserver`
